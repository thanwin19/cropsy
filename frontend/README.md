# Cropsy front end

Agricultural advisory and intelligence for Then Malai (Tenkasi). Built in Lovable (TanStack Start, shadcn/ui, Tailwind v4), with every
feature of the earlier Vite app carried over.

```sh
npm install
npm run dev        # http://localhost:5173 (PORT=... to change); /api, /layers, /images are proxied to the backend on :8000
npm run typecheck
npm test
```

Start the backend first (`python -m uvicorn app.main:app --port 8000` in `backend/`). Set `CROPSY_API_PROXY` to point the dev proxy elsewhere,
or `VITE_CROPSY_API_BASE` to give the browser an API base URL directly (also editable in Settings).

## Where things are
- `src/routes/` pages: `/` Ask (chat + map), `/field`, `/satellite`, `/trust`, `/flagged`, `/runs`, `/settings`.
- `src/features/cropsy/` app shell (rail, alerts and settings sheets), the four screens, `store.tsx` (chat, parcel, attachments, alerts).
- `src/components/` feature components carried over from the earlier app (map engine, advisory cards, stitch views, chat answer card).
- `src/lib/` API client, solar and terrain-shadow maths, colormaps, raster layers. `src/data/villageParcels.generated.ts` is generated by
  `backend/scripts/export_frontend_data.py`.
- Leaflet maps load on the client only (`components/client-lazy.tsx`); keep any new map behind it.
- `npm run horizons[:write]` rebuilds `public/data/then_malai/horizon_profiles.json` from the DEM (see `CHANGES-TERRAIN-SHADOW.md`).
